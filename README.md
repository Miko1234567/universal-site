# Endterm Project: E-Commerce Web Application

* **Student:** Meiirbek Reim (Group SE-2537)

## Architecture & Division of Work
1. **Plain JavaScript (`js/products.js`):** Handles data arrays, dynamic product rendering with loops, image binding, stock alerts, calculated totals with shipping, search/filter/sorting, and complete form validation with `.is-error` / `.is-success` status classes.
2. **jQuery (`js/jquery-main.js`):** Handles selectors, event delegation (`.on()`), traversal (`.closest()`, `.find()`), method chaining, and slide/fade effects.
3. **HTML/CSS Freeze Compliance:** Maintained strictly. No hand-written HTML or CSS additions after the midterm tag; all dynamic UI changes use existing classes.
