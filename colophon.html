Tools used

This website was built entirely by hand using plain HTML, with no CSS, JavaScript or site builders. The code was written in Visual Studio Code and viewed directly in the browser as local files.

Project structure

The project folder is organized like this:

  images/
    autumn-collection.jpg

Working with Git

Every page was tracked with Git and pushed to a GitHub repository. After editing a file, the following commands were used to save the change and upload it:

First, stage the changed files with git add ., then record the change with git commit -m "message", and finally upload it with git push.

A typical successful push looks like this in the terminal: 

Enumerating objects: 3, done.
Writing objects: 100% (3/3), done.
To https://github.com/bazarzok95-art/universal-site.git
 * [new branch]      main -> main

Notes on the markup

Semantic tags such as <header>, <nav>, <main> and <footer> were used on every page instead of generic <div> elements wherever a matching tag existed. A <div> was only used where nothing semantic fit better.
