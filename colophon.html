Project Overview

This website was developed as part of the Web Frontend Development course assignment. It demonstrates pure HTML5 markup and custom CSS3 styling without using any third-party frameworks like Bootstrap or Tailwind.

Technology Stack

  • HTML5: Semantic tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
  • CSS3: Custom layouts using Flexbox and CSS Grid
  • Typography: System font stacks for optimal performance

Design Principles

  • Color Palette: Restricted to 5 core colors for visual consistency
  • Responsive Layout: Flexible grids adapting to screen widths
  • Accessibility: High contrast ratios and clear focus states
